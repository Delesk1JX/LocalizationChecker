# LocalizationChecker 🔍

Программа для проверки русской локализации в модах Minecraft.  
**Работает напрямую с .jar и .zip файлами** — не нужно ничего распаковывать! Автоматически сканирует моды, проверяет наличие `ru_ru.json` или `.lang` файлов внутри архивов и сравнивает ключи с `en_us.json` или `en_US.lang`.

## Возможности

- ✅ **Поддержка множественных форматов архивов**:
  - 📦 .jar файлы (стандартные моды Minecraft)
  - 📦 .zip файлы (архивированные моды)
- ✅ **Поддержка различных путей локализации**:
  - `assets/<modname>/lang/` (стандартный путь для новых модов)
  - `assets/<modname>/language/` (путь для старых модов)
  - `assets/<modname>/lang_nei/` (путь для старых модов — ключи из всех папок объединяются)
- ✅ **Рекурсивное сканирование** — проверяет .jar/.zip файлы во всех подпапках выбранной директории; папки `.connector` и `mcef-cache` пропускаются автоматически
- ✅ **Поддержка папки TranslatedMods** — проверяет внешние переводы до встроенных; автоматически находит папку рядом с директорией модов или внутри `HelperTranslatorRU`
- ✅ **Поддержка JSON с комментариями** — корректно парсит `ru_ru.json` с `//` и `/* */` комментариями
- 📊 **Пять категорий модов**:
  - **[100%] Полный** — 100% совпадение ключей, перевод встроен в .jar
  - **[Частично] Неполный** — есть русский файл, но не все ключи переведены
  - **[Нет] Отсутствует** — нет файла `ru_ru.json` или `ru_RU.lang`
  - **[Переведён]** — 100% перевод из папки TranslatedMods (учитывается отдельно)
  - **[Устарел]** — перевод есть в TranslatedMods, но покрытие < 100% (мод обновился, перевод нет)
- 💾 **Экспорт результатов** в JSON-файл с полной информацией
- 🔍 **Проверка по содержанию** — программа сравнивает именно ключи, а не количество строк
- 📦 **Сохранение лишних ключей** — если в русском файле есть ключи, которых нет в английском, они сохраняются в отчёте (для обратной совместимости)
- 🖥️ **Графический интерфейс** — удобный GUI с вкладками, поиском, сортировкой, контекстным меню и детальным просмотром
- ⚡ **Многопоточная обработка** — быстрая проверка даже 400+ модов
- 🌙 **Поддержка тёмной темы** — автоматически определяет системную тему при запуске
- 🎯 **Поддержка старых модов** — автоматическое распознавание и парсинг файлов `.lang` для Minecraft 1.12.2 и ниже

## 🛠️ Использование

### Графический интерфейс (рекомендуется)

Просто запустите программу:

```bash
# Из исходного кода
python check_localization.py

# Или готовый исполняемый файл
./dist/LocalizationChecker
```

В GUI вы сможете:
1. Нажать **"📁 Выбрать папку с модами"** или **перетащить папку прямо в окно** (требует `tkinterdnd2`)
2. Нажать **"▶️ Проверить"** для начала сканирования
3. Нажать **"🔄 Обновить"** для повторного сканирования без выбора папки заново
4. Просмотреть результаты по вкладкам: **[100%] Полный (N)**, **[Частично] Неполный (N)**, **[Нет] Отсутствует (N)**, **[Переведён] (N)**, **[Устарел] (N)**
5. **Двойной клик** на моде или **ПКМ → Подробнее** откроет окно деталей с двумя колонками ключей, прокруткой и кнопками копирования
6. **ПКМ** на строке также предлагает: **Скопировать** название мода, **Вставить** текст в строку поиска, **Расположение** — открыть папку с .jar в проводнике
7. **Ctrl+C** копирует выделенный мод в активной вкладке
8. Нажать **"📂 TranslatedMods"** для открытия папки переводов в проводнике
9. Нажать **"💾 Экспорт в JSON"** для сохранения отчёта
10. Использовать строку **поиска** для фильтрации по имени мода
11. Кликать на **заголовки столбцов** для сортировки

### Drag & Drop

Для поддержки перетаскивания папок установите дополнительную библиотеку:

```bash
pip install tkinterdnd2
```

После этого можно перетащить папку с модами прямо в окно программы — она заменит диалог выбора папки. Если `tkinterdnd2` не установлен, программа работает в обычном режиме без drag & drop.

### Консольная версия

```bash
# Проверка текущей директории
python check_localization.py .

# Проверка конкретной папки
python check_localization.py C:\Games\Minecraft\mods

# Указать папку TranslatedMods вручную
python check_localization.py --translated_mods C:\path\to\TranslatedMods

# Сохранить в другой файл
python check_localization.py -o results.json

# Запустить GUI явно
python check_localization.py --gui
```

## 📁 Папка TranslatedMods

Программа поддерживает внешние переводы через папку `TranslatedMods`. Структура:

```
TranslatedMods/
├── <название_мода>/
│   └── lang/
│       ├── ru_ru.json   (для Minecraft 1.13+)
│       └── ru_RU.lang   (для Minecraft 1.12.2 и ниже)
```

Папка ищется автоматически в нескольких местах рядом с директорией модов. Моды с переводом из `TranslatedMods` и полным покрытием (100%) выделяются в отдельную категорию **[Переведён]**. Если перевод есть, но покрытие неполное (мод обновился и добавил новые ключи) — мод попадает в категорию **[Устарел]**. Обе категории не учитываются в счётчиках остальных категорий.

### Поля в отчёте:

| Поле | Описание |
|---|---|
| `mod_name` | Имя .jar файла и assets-имя мода в скобках |
| `status` | Статус: `full` / `partial` / `missing` / `translated` |
| `source` | Источник перевода: `jar` / `translated_mods` / `none` |
| `ru_keys` | Количество ключей в русском файле |
| `en_keys` | Количество ключей в английском файле |
| `percentage` | Процент переведённых ключей |
| `missing_keys` | Ключи из en_us, которых **нет** в ru_ru (нужно перевести) |
| `extra_keys` | Ключи из ru_ru, которых **нет** в en_us (для совместимости) |
| `error` | Сообщение об ошибке, если возникла проблема |

## 💡 Советы по использованию

1. **Ничего не нужно распаковывать** — программа работает напрямую с .jar файлами
2. **Начните с вкладки [Устарел]** — там переводы уже есть, но нужно добавить несколько ключей
3. **Анализируйте missing_keys** — в окне деталей и JSON-отчёте есть точный список ключей для перевода
4. **Сортируйте по %** — начните с модов у которых 80–99%, их легче всего завершить
5. **Используйте поиск** — строка поиска фильтрует по имени одновременно во всех вкладках
6. **Лишние ключи — не ошибка** — `extra_keys` сохраняются для обратной совместимости со старыми версиями модов
7. **Рекурсивное сканирование** — можно указать корневую папку экземпляра, программа найдёт моды во всех подпапках

## ⚠️ Важные замечания

- **Полный перевод = строго 100%** — даже один отсутствующий ключ делает перевод неполным
- Программа сравнивает **ключи**, а не значения — важно наличие ключа, а не качество перевода
- Моды без файла `en_us.json` / `en_US.lang` **не учитываются** при проверке
- Поддерживаются оба формата путей в архиве: прямой слэш `/lang/` и обратный `\lang\`
- Категории **[Переведён]** и **[Устарел]** не входят в счётчики Полный/Неполный/Нет — это отдельные группы
- При сканировании папки `.connector` и `mcef-cache` пропускаются автоматически

# LocalizationChecker 🔍

Программа для проверки локализации в модах Minecraft (по умолчанию — русской, целевой язык можно сменить).  
**Работает напрямую с .jar и .zip файлами** — не нужно ничего распаковывать! Автоматически сканирует моды, проверяет наличие файла целевого языка (например, `ru_ru.json` или `ru_RU.lang`) внутри архивов, сравнивает ключи с `en_us.json`/`en_US.lang`, а также проверяет перевод гайдбуков **Patchouli**.

## Возможности

- ✅ **Поддержка множественных форматов архивов**: .jar и .zip
- 🌍 **Любой целевой язык перевода** — по умолчанию `ru_ru`, но можно выбрать другой (`uk_ua`, `de_de`, `zh_cn` и т.д.) через выпадающий список в GUI, поле `target_language` в `config.json` или ключ `--lang` в консоли; код нормализуется (`RU` → `ru_ru`, `de-DE` → `de_de`)
- ✅ **Поддержка различных путей локализации**:
  - `assets/<modname>/lang/` (стандартный путь для новых модов)
  - `assets/<modname>/language/` (путь для старых модов; ключи из всех найденных папок объединяются)
- ✅ **Рекурсивное сканирование** — проверяет .jar/.zip файлы во всех подпапках выбранной директории; папки `.connector` и `mcef-cache` пропускаются автоматически
- ✅ **Поддержка папки TranslatedMods** — проверяет внешние переводы до встроенных; автоматически находит папку рядом с директорией модов или внутри `HelperTranslatorRU`
- ✅ **Поддержка JSON с комментариями** — корректно парсит JSON с `//` и `/* */` комментариями
- 📖 **Поддержка гайдбуков Patchouli** — отдельно проверяет перевод страниц гайдбука (`entries/`, `categories/`) как в .jar, так и в TranslatedMods; мод с непереведённым гайдбуком не попадёт в «Полный», даже если основные ключи переведены на 100%
- ⚠️ **Поиск «≈ Совпадает с EN»** — находит ключи, значение которых совпадает с английским (частый признак забытой строки). Коды форматирования `§x` и плейсхолдеры (`%s`, `{}`) при этом совпадением не считаются
- ⭕ **Пустые значения** — ключ есть, но значение пустое: собираются отдельным списком и по умолчанию **не** портят процент. Включить `count_empty_as_missing` в `config.json`, и тогда они будут считаться «не хватает»
- 📊 **Пять категорий модов**:
  - **[100%] Полный** — 100% совпадение ключей (и гайдбука, если есть), перевод встроен в .jar
  - **[Частично] Неполный** — есть файл целевого языка, но не все ключи/страницы гайдбука переведены
  - **[Нет] Отсутствует** — нет файла целевого языка (например, `ru_ru.json` или `ru_RU.lang`)
  - **[Переведён]** — 100% перевод из папки TranslatedMods (учитывается отдельно)
  - **[Устарел]** — перевод есть в TranslatedMods, но покрытие < 100% (мод обновился, перевод отстал)
- ⚠️ **Вкладка «Ошибки»** — все предупреждения и проблемы сканирования в одном месте, с копированием и очисткой; полная история пишется в ротируемый лог `localization_checker.log`
- ☑️ **Чекбоксы в списке модов** — отметьте нужные моды кликом по квадратику или клавишей **Enter**; кнопка «Выбрать все/Снять все» массово управляет отметками, рядом показывается счётчик «Выбрано: N»
- 📋 **«Скопировать моды»** — копирует .jar/.zip файлы отмеченных (или всех видимых) модов активной вкладки в выбранную папку
- 🎨 **Настраиваемая подсветка строк по проценту** во вкладке «Неполный»: 75–99% / 50–74% / <50% — цвета задаются в `config.json`
- 📦 **Извлечение заготовок для перевода** — отдельный инструмент, который сам создаёт папку `TranslatedMods`-совместимой структуры из выбранных модов (подробнее ниже)
- 💾 **Экспорт результатов** в JSON-файл с полной информацией
- 🔍 **Проверка по содержанию** — сравниваются именно ключи, а не количество строк
- 📦 **Сохранение лишних ключей** — ключи в файле перевода, которых нет в английском, сохраняются в отчёте (для обратной совместимости)
- 🖥️ **Графический интерфейс** — вкладки, поиск, сортировка, контекстное меню, детальный просмотр с двумя вкладками (ключи / гайдбук)
- 🪟 **Запоминает геометрию окна и ширины колонок** — при следующем запуске всё восстанавливается
- ⚡ **Многопоточная обработка** — быстрая проверка даже 400+ модов: каждый .jar/.zip открывается ровно один раз за проверку
- 🌙 **Поддержка тёмной темы** — определяется автоматически при запуске, переключается мгновенно везде, включая открытые окна деталей
- 💾 **Запоминает последнюю папку** — при следующем запуске автоматически подставляет последнюю использованную папку с модами
- ⌨️ **Раскладко-независимые горячие клавиши** — Ctrl+C, Ctrl+A, Ctrl+V и F5 работают одинаково что на английской, что на русской раскладке
- 🎯 **Поддержка старых модов** — автоматический парсинг `.lang` файлов для Minecraft 1.12.2 и ниже (в том числе комментарии с `#` и `//`)

## 🛠️ Использование

### Графический интерфейс (рекомендуется)

```bash
# Из исходного кода
python check_localization.pyw

# Или готовый исполняемый файл
./dist/LocalizationChecker
```

В GUI вы сможете:
1. Нажать **"📁 Выбрать папку с модами"** или **перетащить папку прямо в окно** (требует `tkinterdnd2`)
2. При необходимости сменить **целевой язык** в выпадающем списке «Язык:» (справа в тулбаре); после смены нажмите «🔄 Обновить» (F5)
3. Нажать **"▶️ Проверить"** для начала сканирования
4. Нажать **"🔄 Обновить"** (или клавишу **F5**) для повторного сканирования той же папки
5. Просмотреть результаты по вкладкам: **[100%] Полный (N)**, **[Частично] Неполный (N)**, **[Нет] Отсутствует (N)**, **[Переведён] (N)**, **[Устарел] (N)** и **⚠️ Ошибки (N)**
6. Отметить моды **чекбоксами** в колонке «Мод» (клик по квадратику слева или **Enter** на выделенной строке) и скопировать их файлы кнопкой **"📋 Скопировать моды"**; если ничего не отмечено — скопируются все видимые моды вкладки
7. **Двойной клик** на моде или **ПКМ → Подробнее** откроет окно деталей с двумя вкладками (окно открывается просторным — `1000×640`, его можно растягивать; повторный вызов для того же мода не создаёт дубль, а поднимает уже открытое окно):
   - **🔑 Ключи локализации** — четыре списка: **❌ Не хватает**, **➕ Лишние ключи**, **⚠️ ≈ Совпадает с EN** и **⭕ Пустые**; у каждого своя кнопка «Скопировать всё», а **Ctrl+C** копирует выделенные строки
   - **📖 Гайдбук** — статус перевода Patchouli-гайдбука мода (если есть), список непереведённых страниц с копированием
8. **ПКМ** на строке также предлагает: **Скопировать** название мода, **Вставить** текст в строку поиска, **Расположение** — открыть папку с .jar в проводнике, **Открыть в TranslatedMods** — открыть/создать папку перевода этого мода
9. **Ctrl+C** копирует выделенный мод в активной вкладке, **Ctrl+A** и **Ctrl+C**/**Ctrl+V** в строке поиска работают на любой раскладке клавиатуры
10. Нажать **"📂 TranslatedMods"** для открытия папки переводов в проводнике (можно указать вручную, если ещё не настроена)
11. Нажать **"📦 Извлечь для перевода"** — открыть инструмент подготовки заготовок перевода (см. ниже)
12. Нажать **"💾 Экспорт в JSON"** для сохранения отчёта
13. Использовать строку **поиска** для фильтрации по имени мода (фильтр применяется к активной вкладке, остальные достраиваются при переключении)
14. Кликать на **заголовки столбцов** для сортировки (включая «Не хватает» и «Совпд. с EN» — начните с модов, где больше подозрительных строк)

### 📦 Извлечь для перевода

Отдельный инструмент внутри программы (кнопка в тулбаре), который автоматизирует рутину: вместо того чтобы вручную открывать каждый `.jar` архиватором и копировать `lang`-файлы, программа делает это сама.

1. Укажите **папку с модами** (можно ту же, что и для проверки) и **папку для сохранения**
2. По желанию включите галочку **«Если в TranslatedMods уже есть перевод — брать его вместо встроенного в мод»**
3. Нажмите **"▶️ Начать"**
4. Для каждого мода программа создаст `<output>/<modname>/lang/`:
   - `en_us.json` (или `en_US.lang` для старых модов) — всегда актуальный референс
   - файл целевого языка (например, `ru_ru.json`) — берётся из мода, если перевод уже есть внутри .jar; если нет — создаётся заготовка (копия английского текста), готовая для перевода
5. Если в моде есть **гайдбук Patchouli**, его страницы также извлекаются: `<output>/<modname>/patchouli_books/<book>/en_us/...` и `<target_lang>/...` (с тем же принципом — копия перевода или заготовка из английского)
6. Если в выходной папке уже есть готовые переводы — программа спросит **один раз в начале**, перезаписывать их или нет, и применит ответ ко всем модам разом

Результат получается сразу в формате, который понимает `TranslatedMods` — можно указать эту же папку как папку переводов.

### Drag & Drop

```bash
pip install tkinterdnd2
```

После этого можно перетащить папку с модами прямо в окно программы. Если `tkinterdnd2` не установлен, программа работает в обычном режиме без drag & drop.

```bash
# Проверка текущей директории

# Указать папку TranslatedMods вручную

# Сохранить в другой файл

# Запустить GUI явно
python check_localization.pyw --gui
```

## 📁 Папка TranslatedMods

```
TranslatedMods/
├── <название_мода>/
│   ├── lang/
│   │   ├── ru_ru.json   (для Minecraft 1.13+)
│   │   └── ru_RU.lang   (для Minecraft 1.12.2 и ниже)
│   └── patchouli_books/
│       └── <book_id>/
│           └── ru_ru/
│               ├── entries/...
│               └── categories/...
```

Папка ищется автоматически в нескольких местах рядом с директорией модов. Моды с переводом из `TranslatedMods` и полным покрытием (100%, включая гайдбук) попадают в категорию **[Переведён]**. Если перевод есть, но покрытие неполное — в **[Устарел]**. Обе категории не учитываются в счётчиках остальных категорий.

## ⚙️ config.json

Создаётся и обновляется автоматически (всегда рядом со скриптом, независимо от текущей директории запуска). Основные поля:

```json
{
  "translated_mods_path": "TranslatedMods",
  "target_language": "ru_ru",
  "max_workers": 4,
  "default_export_file": "localization_results.json",
  "show_completion_popup": false,
  "count_empty_as_missing": false,
  "last_directory": "C:\\путь\\к\\последней\\папке",
  "row_colors": {
    "light": { "jar": "#d4f4dd", "translated_mods": "#9dcafa", "missing": "#ffe4e1" },
    "dark":  { "jar": "#7d8a7d", "translated_mods": "#5f738c", "missing": "#b18a82" }
  },
  "percentage_colors": {
    "light": { "high": "#fff3b0", "mid": "#ffd9a0", "low": "#ffc2c2" },
    "dark":  { "high": "#6b6b2e", "mid": "#7a5a2e", "low": "#7a3b3b" }
  }
}
```

- **`translated_mods_path`** — путь к папке внешних переводов
- **`target_language`** — код целевого языка перевода (`ru_ru`, `uk_ua`, `de_de`, …); меняется и через GUI, и через `--lang`
- **`max_workers`** — количество потоков сканирования
- **`default_export_file`** — имя файла по умолчанию для экспорта
- **`show_completion_popup`** — показывать всплывающее окно по завершении проверки
- **`count_empty_as_missing`** — считать ключи с пустым значением как «не хватает» (по умолчанию `false`: они видны отдельным списком, но процент не портят)
- **`last_directory`**, **`last_extract_source`**, **`last_extract_output`**, **`last_copy_mods_dir`** — запомненные пути (папка модов, диалоги извлечения и копирования)
- **`extract_use_translated_mods`** — последнее состояние галочки «брать перевод из TranslatedMods» в инструменте извлечения
- **`window_geometry`**, **`column_widths`** — размер/положение окна и ширины колонок таблиц (восстанавливаются при запуске)
- **`row_colors`** — цвет строки в зависимости от источника перевода (jar / TranslatedMods / отсутствует)
- **`percentage_colors`** — цвет подсветки строки во вкладке «Неполный» в зависимости от процента: `high` (75–99%), `mid` (50–74%), `low` (<50%)

Оба блока цветов задаются отдельно для светлой (`light`) и тёмной (`dark`) темы. Если поля нет в файле — используются значения по умолчанию.

## 📝 Логирование

Программа пишет подробный лог в `localization_checker.log` рядом со скриптом (ротация: 1 МБ, до 2 копий). В GUI предупреждения и ошибки сканирования дополнительно собираются на вкладке **⚠️ Ошибки** — их можно скопировать целиком или по одной строке и очистить список. Сюда же попадают повреждённые архивы: мод, который не удалось открыть, не исчезает молча.

## 📤 Формат выходного файла

```json
{
  "scan_directory": "C:/Games/Minecraft/mods",
  "total_mods": 134,
  "summary": {
    "full_translation": 28,
    "partial_translation": 42,
    "missing_translation": 52,
    "translated_mods": 12,
    "outdated_translation": 3
  },
  "mods": {
    "full": [
      {
        "mod_name": "additionaladditions-6.0.1.jar (additionaladditions)",
        "status": "full",
        "source": "jar",
        "ru_keys": 93,
        "en_keys": 93,
        "percentage": 100.0,
        "missing_keys": [],
        "extra_keys": [],
        "identical_keys": [],
        "identical_count": 0,
        "empty_keys": [],
        "empty_count": 0,
        "error": null,
        "patchouli": []
      }
    ]
  }
}
```

### Поля в отчёте:

| Поле | Описание |
|---|---|
| `mod_name` | Имя .jar файла и assets-имя мода в скобках |
| `status` | Статус: `full` / `partial` / `missing` / `translated` / `outdated` |
| `source` | Источник перевода: `jar` / `translated_mods` / `none` |
| `ru_keys` | Количество ключей в файле целевого языка |
| `en_keys` | Количество ключей в английском файле |
| `percentage` | Процент переведённых ключей |
| `missing_keys` | Ключи из en_us, которых **нет** в переводе |
| `extra_keys` | Ключи из перевода, которых **нет** в en_us |
| `identical_keys` | Ключи, значение которых совпадает с английским (возможно, забыли перевести) |
| `identical_count` | Количество таких ключей |
| `empty_keys` | Ключи, которые есть, но значение пустое |
| `empty_count` | Количество таких ключей |
| `error` | Сообщение об ошибке, если возникла проблема |
| `patchouli` | Список гайдбуков мода со статусом перевода (`status`, `percentage`, `missing_files`, `extra_files`) |

## 💡 Советы по использованию

1. **Ничего не нужно распаковывать** — программа работает напрямую с .jar файлами
2. **Начните с вкладки [Устарел]** — там переводы уже есть, но нужно добавить несколько ключей
3. **Используйте «Извлечь для перевода»** — не открывайте архивы вручную, программа сама подготовит заготовки, включая гайдбуки
4. **Анализируйте missing_keys** — в окне деталей (вкладка «Ключи локализации») и в JSON-отчёте есть точный список того, что нужно перевести
5. **Проверяйте колонку «Совпд. с EN»** — строки, совпадающие с английскими, часто оказываются забытыми; в окне деталей они собраны в отдельном списке
6. **Проверяйте список «Пустые»** — ключ может формально присутствовать, но быть незаполненным
7. **Проверяйте вкладку «Гайдбук»** в окне деталей — мод может показывать 100% по ключам, но иметь непереведённый Patchouli-гайдбук
8. **Отмечайте моды чекбоксами** (клик или Enter) и копируйте их одной кнопкой — удобно, чтобы забрать все недопереведённые моды в рабочую папку
9. **Сортируйте по %** — начните с модов у которых 80–99%, их легче всего завершить
10. **Настройте цвета подсветки** под себя через `percentage_colors` в `config.json`
11. **Загляните на вкладку «Ошибки»** — если мод не попал в результаты, причина будет там (и в `localization_checker.log`)

## 🧹 Удаление дубликатов ключей (remove_duplicates.py)

Отдельная утилита для чистки локализаций, в которых один и тот же ключ встречается несколько раз (частая ошибка при ручном переводе и слиянии правок).

```bash
python remove_duplicates.py
```

**Что она делает:**
- находит и удаляет повторяющиеся ключи — в том числе внутри вложенных объектов
- **починяет недостающие запятые**: если `json` ругается на `Expecting ',' delimiter`, инструмент сам дорисует запятую (в конец предыдущей строки) и продолжит
- сохраняет **исходное форматирование**: комментарии (`//`, `/* */`, `#` в стиле Minecraft), пустые строки, отступы, BOM, кодировку (в т.ч. cp1251) и переводы строк (LF/CRLF). Файл не пересобирается через `json.dumps` — правятся только нужные строки
- оставляет первое или последнее вхождение — на ваш выбор

**Что она НЕ делает:** не чинит другие ошибки синтаксиса (пропущенное двоеточие, незакрытую скобку) — такой файл будет помечен как «пропущен» с указанием строки и столбца.

### Галочки в окне

| Галочка | По умолчанию | Смысл |
|---|---|---|
| Включая подпапки | вкл | обход дерева каталогов |
| Только языковые файлы | вкл | `*.ru_ru.json` и всё, что внутри папок `lang`/`language`. Без этого галочки инструмент возьмёт и `blockstates`, модели, страницы гайдбуков |
| Починить пропущенные запятые | вкл | дорисовывать запятые автоматически |
| Оставлять первое вхождение | вкл | иначе остаётся последнее |
| **Только отчёт (не записывать)** | **вкл** | прогон только показывает, что изменится, ничего не записывая |

Выбор галочек запоминается в `remove_duplicates.json` рядом со скриптом.

> Никакие папки не исключаются — обрабатывается всё, что нашлось. Русские буквы, пробелы и любой регистр в именах папок поддерживаются. Если «подходящих файлов» не оказалось, но что-то отсеял фильтр «только языковые», программа сообщит, сколько именно, и предложит снять галочку.

### Копирование пути

Путь из строки «Директория:» можно скопировать кнопкой **📋 Копировать путь** или правым кликом по самой строке (там же «Открыть в проводнике») — удобно, чтобы не выделять текст мышью.

### Защита переводов

- Перед первой правкой файл копируется в `backup_ГГГГММДД_ЧЧММСС/` по тому же пути
- Запись **атомарная**: временный файл + переименование, файл не остаётся наполовину записанным
- После записи файл перечитывается и проверяется: парсится ли, не осталось ли дубликатов, совпали ли данные с ожидаемыми. При несовпадении — автооткат из резервной копии
- Кнопка **«↩ Откатить»** возвращает файлы из последнего бэкапа
- Кнопка **«⏹ Остановить»** прерывает сканирование
- Двойной клик по строке в логе показывает, что изменится: удалённые ключи, вставленные запятые и unified diff
- Подробности пишутся в `remove_duplicates.log` (ротация 1 МБ)

## ⚠️ Важные замечания

- **Полный перевод = строго 100%**, включая гайдбук Patchouli, если он есть у мода
- Программа сравнивает **ключи**, а не значения — важно наличие ключа, а не качество перевода (совпадения значений с английским показываются отдельно как «≈ Совпадает с EN», пустые значения — как «Пустые»)
- Моды без файла `en_us.json` / `en_US.lang` **не учитываются** при проверке
- Повреждённые архивы не открываются: мод не попадёт в таблицы, но будет указан на вкладке «Ошибки»
- Поддерживаются оба формата путей в архиве: `/lang/` и `\lang\`
- Категории **[Переведён]** и **[Устарел]** не входят в счётчики Полный/Неполный/Нет — это отдельные группы
- При сканировании папки `.connector` и `mcef-cache` пропускаются автоматически
- В инструменте «Извлечь для перевода» файл `en_us`/`en_US.lang` в выходной папке всегда перезаписывается актуальной версией из мода — перезаписи подлежит только файл целевого языка, и только с вашего подтверждения
